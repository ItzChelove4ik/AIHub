# Веб-режим: сайты ChatGPT, Claude и Gemini внутри AIHub

Решение для фазы 3 (iOS). Записано 2026-11-24.

## Что делаем

На главном экране, кроме чатов через API, есть карточки «ChatGPT (сайт)», «Claude (сайт)»,
«Gemini (сайт)». Каждая открывает официальный сайт (`chatgpt.com`, `claude.ai`,
`gemini.google.com`) во встроенном `WKWebView`:

- трафик идёт тем же путём, что и у остального приложения: напрямую, а при «белых списках»
  через туннель OpenFlux (`WKWebsiteDataStore.proxyConfigurations` → SOCKS5 127.0.0.1:1080);
- у каждого сайта своё постоянное хранилище данных (`WKWebsiteDataStore(forIdentifier:)`),
  поэтому вход сохраняется между запусками и сайты не видят данные друг друга;
- фото и файлы: штатная кнопка загрузки сайта. `WKWebView` сам показывает выбор
  «Камера / Медиатека / Файлы» для `<input type="file">`; нужны `NSCameraUsageDescription`
  и `NSPhotoLibraryUsageDescription` в Info.plist;
- кнопки «назад», «обновить», «открыть в Safari», индикатор загрузки.

## Чего не делаем (и почему)

- **Приложение не читает cookies и токены сайтов, не передаёт их на сервер и не управляет
  страницей скриптами.** Использование потребительских подписок (ChatGPT Plus, Claude Pro/Max,
  Gemini Advanced) из сторонних программ запрещено условиями провайдеров, за это блокируют
  аккаунты. Сервер AIHub работает только с API-ключами и OAuth OpenRouter.
- **Не подменяем User-Agent, чтобы обойти запрет Google.** Google не разрешает вход
  в Google-аккаунт во встроенных WebView (ошибка `disallowed_useragent`). Поэтому:
  - Gemini (вход только через Google), скорее всего, не даст войти в веб-режиме;
  - на ChatGPT и Claude вход «через Google» не сработает, работает вход по email
    (пароль или код из письма) и, где есть, «через Apple».
  Для Gemini в AIHub остаётся чат через API (ключ из AI Studio).

## Где это видно пользователю

В карточке веб-режима мелким текстом: «Это сайт провайдера. Вход и переписка остаются
на этом iPhone и не попадают на сервер AIHub».
