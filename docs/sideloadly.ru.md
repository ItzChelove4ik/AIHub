# Установка AIHub на iPhone через Sideloadly (Windows)

AIHub собирается без подписи на GitHub Actions (`.github/workflows/ios.yml`), а
подписывает его Sideloadly вашим бесплатным Apple ID.

## 1. Скачать IPA

- Из релиза: GitHub → Releases → `AIHub.ipa` (появляется для тегов `v*`);
- или из последней сборки: GitHub → Actions → **ios** → последний успешный запуск →
  артефакт **AIHub-ipa** (zip с `AIHub.ipa` внутри).

## 2. Поставить Sideloadly

1. Установите iTunes и iCloud **с сайта Apple** (не из Microsoft Store) — Sideloadly
   нужны их драйверы.
2. Скачайте Sideloadly с sideloadly.io и установите.
3. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять этому компьютеру».

## 3. Установить

1. Перетащите `AIHub.ipa` в окно Sideloadly.
2. Выберите iPhone, введите Apple ID (лучше отдельный, не основной).
3. Нажмите **Start**. При первом входе Apple попросит код двухфакторной проверки.

## 4. Разрешить запуск на iPhone

1. **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим
   разработчика → включить, перезагрузить iPhone, подтвердить.
2. **Доверие профилю**: Настройки → Основные → VPN и управление устройством → ваш
   Apple ID → «Доверять».

## 5. Первый запуск

1. Введите адрес сервера (его выводит `deploy/install.sh`, например
   `https://1-2-3-4.sslip.io:8443`).
2. Если мобильный интернет работает только по «белым спискам», вставьте или
   отсканируйте ссылку канала `openflux://…` от администратора.
3. Войдите или зарегистрируйтесь (по приглашению, если сервер так настроен).

## Ограничения бесплатного Apple ID

- Подпись действует **7 дней**. Потом приложение перестаёт открываться, пока его не
  переподписать. В Sideloadly включите автообновление (Auto-refresh): он переподписывает
  приложение по Wi-Fi, когда iPhone и компьютер в одной сети и Sideloadly запущен.
- Не больше **3 приложений** одновременно на один бесплатный Apple ID.
- Нет Network Extension, App Groups и Push: AIHub их и не использует. Туннель OpenFlux
  работает внутри приложения и останавливается, когда оно уходит в фон.
